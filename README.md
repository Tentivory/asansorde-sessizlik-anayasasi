# Asansörde Sessizlik Anayasası

> Kabin küçüktür. Kanun büyüktür. Sen susarsın.

Bu depo, insanlığın asansör içinde konuşma sapkınlığına karşı yazılmış **en resmi, en gereksiz ve en çalışan** protokoldür.

Uluslararası Asansör Hukuku Enstitüsü (uydurma) tarafından **ISO-SESSIZ-9001** belgesi verilmiştir. Belge çerçeve içinde değildir çünkü çerçeve gürültü yapar.

## Bu yazılım ne yapar?

1. Bindigin katı ve ineceğin katı alır.
2. Ağzını açtıysan yargılar.
3. Açmadıysan yine yargılar ama daha kibar.
4. Çıkış kodu: sessizsen `0`, konuştuysan `1`. Evet, konuşmak hatadır.

## Kurulum

```bash
python3 anayasa.py --nereden 2 --nereye 7
```

Konuştuysan (yazık):

```bash
python3 anayasa.py --nereden 0 --nereye 12 --konustu
```

Gizli dipnotu görmek istersen (görme, işin yok):

```bash
python3 anayasa.py --gizli-dipnot
```

## Anayasal ilkeler

- Nefes almak serbesttir, ritim tutmak değil.
- Kat düğmesine basmak bir oy değildir; sadece bir tercihtir. Tercihler sessiz olur.
- Ayna, tanıktır. Ayna ifade vermez.
- Kapı kapandıktan sonra "bir saniye" demek, anayasa ihlalidir.
